# 品牌竞品分析研究

## 概览

接收用户提供的品牌+竞品+产品线+数据，自动化执行多维度竞品研究，输出完整的 Markdown 格式分析报告。

## 触发条件

用户提供了以下任一或全部信息：
- 目标品牌名称
- 竞品品牌列表（1个或多个）
- 具体产品线
- 研究目的（竞标提案/市场洞察/内容策略等）

> 若用户未主动提供上述信息，通过提问补充完整。

## 工作流程

### 第一步：收集研究背景（对话中获取）

| 信息项 | 说明 | 示例 |
|--------|------|------|
| 目标品牌 | 待分析的主品牌 | 怡宝 |
| 竞品列表 | 同品类竞争品牌 | 元气森林、东方树叶、柠檬共和国、蜂解 |
| 研究产品线 | 具体运营的产品线 | 蜜水系列、至本清润、FEEL气泡水、佐味茶事 |
| 抖音数据 | 观看量/点赞/评论数据 | 品牌官方账号粉丝数、高播放量视频链接 |
| 抖音登录凭证 | 是否提供已登录账号 | 用户提供 cookie / 我方扫码登录 |
| 研究目的 | 最终用途 | DP代运营竞标 / 内部策略参考 / 竞品提案 |
| 报告用途 | 对外/对内 | 对外提案（需更精炼） / 对内研究（可详细） |

### 第二步：多源数据采集

#### 2.1 抖音账号登录抓取（优先执行）

**使用 browser-automation skill（CDP模式）**

抖音平台数据封闭，外部无法直接抓取，因此优先通过登录态获取真实数据。

**适用场景：**
- 获取品牌官方账号真实粉丝数、获赞数
- 抓取高播放量视频列表（含播放量/点赞/评论/分享数据）
- 分析竞品种草达人矩阵（合作视频列表）
- 提取评论热词、用户情感倾向

**抓取步骤：**

```
① 登录抖音
  → 使用 browser-automation CDP模式连接用户已登录的 Chrome
  → 若无登录态，引导用户扫码登录（手机抖音App扫码）
  
② 获取目标账号基础数据
  → 导航至 [品牌名] 官方旗舰店主页
  → 提取：粉丝数、获赞数、关注数、抖音号
  → 截图留存
  
③ 抓取视频列表数据
  → 进入账号主页视频 tab
  → 滚动加载至少 30 条视频
  → 提取每条视频的：
    - 标题
    - 发布时间
    - 播放量（w+ / 10w+ / 100w+）
    - 点赞数
    - 评论数
    - 转发/分享数
  → 按播放量降序排列，标注 >30万播放的视频
  
④ 竞品种草矩阵分析（针对竞品）
  → 在抖音搜索 [竞品名]
  → 进入"商品" tab，查看合作带货视频
  → 提取合作达人类型（头部/腰部/KOC）
  → 提取种草内容类型（测评/场景/剧情）
  
⑤ 提取评论热词
  → 进入播放量最高的前3条视频评论区
  → 提取高频评论关键词
  → 分析用户关注点（口感/包装/价格/功效）
```

**注意事项：**
- 抖音有反爬限制，每次滚动后适当停顿（1-2秒）
- 播放量显示为"10w+"格式，截图留存以便引用
- 用户需配合扫码登录（手机抖音 App → 我 → 右上角扫码）

**登录凭证获取：**
```
browser CDP模式 → 打开抖音网页版(douyin.com) 
→ 若未登录 → 用户手机扫码 → 登录态持久化
→ 登录成功后可复用 Cookie，无需重复登录
```

#### 2.2 品牌基础信息检索（无登录态时补充）

**检索关键词模板：**

**检索工具优先级：**
1. Google搜索（EDGE浏览器，最稳定）→ 首选
2. 百度百科/品牌官网 → 次选
3. 百度搜索（易遭遇安全验证拦截）

**常用信息源：**
| 信息类型 | 来源 |
|---------|------|
| 品牌历史 | 百度百科、品牌官网 |
| 财务数据 | 东方财富、新浪财经、港交所披露 |
| 营销动作 | 微博/品牌官微、知乎、界面新闻 |
| 行业数据 | 魔镜洞察、情报通、欧睿咨询 |

#### 2.3 竞品营销动作检索

针对每个竞品，检索近1-2年营销动作：

**检索维度：**

**检索关键词模板：**

## 技术工具说明

### 浏览器工具（首选）

```
browser-tool open-url  → 打开百度/Google搜索结果页面
browser-tool snapshot  → 提取页面可见内容
browser-tool extract   → 精准提取关键信息
```

### 抖音抓取专用（browser-automation skill - CDP模式）

```
browser-automation handleNewPage({url})    → 新开页面
browser-automation handleScreenshot()       → 截图（抖音视频数据）
browser-automation handleGetContent()       → 提取页面文字内容
browser-automation handleClick()           → 点击加载更多/切换tab
browser-automation handleScroll()          → 滚动加载视频列表
browser-automation handleWait()             → 等待元素加载
```

### 抖音抓取标准流程

```javascript
// Step 1: 打开账号主页
handleNewPage({url: 'https://www.douyin.com/user/[账号ID]'})

// Step 2: 等待页面加载
handleWait({selector: '[data-e2e="user-post-list"]', timeout: 10000})

// Step 3: 截图账号基础信息
handleScreenshot({fullPage: false})

// Step 4: 滚动加载视频列表（重复3-5次）
handleScroll({direction: 'down', amount: 3})
handleWait({selector: 'video-item', timeout: 3000})

// Step 5: 提取视频数据
handleGetContent({selector: '[data-e2e="user-post-list"]'})

// Step 6: 截图保存
handleScreenshot({})
```

### 常见障碍与处理

| 障碍 | 解决方案 |
|------|---------|
| 百度安全验证拦截 | 改用 Google 搜索（EDGE浏览器） |
| 部分URL fetch失败 | 通过 browser open-url 打开再提取 |
| 抖音数据封闭 | **优先用CDP登录抓取；无账号则标注"用户提供"** |
| 财报数据缺失 | 使用魔镜洞察等第三方数据补充 |
| 抖音反爬（滚动限制） | 每次滚动后等待2秒，避免高频请求 |
| 扫码登录超时 | 告知用户在60秒内完成扫码 |

## 输出质量标准

1. **数据可溯源**：每个数据点注明来源（抓取/媒体/年报/用户提供）
2. **抖音数据优先抓取**：登录态获取的数据优先于估算数据
3. **建议可落地**：借鉴方向包含具体动作，非空泛概念
4. **格式统一**：使用表格对比，结构清晰
5. **免责声明**：报告开头注明数据局限和用途限制
6. **符合用途**：对外提案风格精炼，对内研究风格详细
