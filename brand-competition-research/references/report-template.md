## 二、抖音抓取方法论（CDP登录模式）

### 何时优先使用登录抓取

| 场景 | 登录抓取 | 替代方案 |
|------|---------|---------|
| 获取真实粉丝数/获赞数 | ✅ 必须 | 估算/用户提供 |
| 抓取视频播放量/点赞/评论 | ✅ 必须 | 无法获取 |
| 分析竞品种草达人矩阵 | ✅ 必须 | 手动搜索 |
| 用户提供抖音cookie | ✅ 优先 | 直接使用cookie |
| 无登录态 + 用户不配合 | ❌ 无法 | 标注"数据不可获取" |

### CDP登录抓取标准流程

#### 阶段一：登录态准备

```
1. 检查现有cookie
   → browser-automation handleNewPage({url: 'https://www.douyin.com'})
   → 判断是否已登录（观察右上角头像）

2. 若未登录，引导用户扫码
   → 打开登录页面
   → 提示用户："请用手机抖音App扫码登录（我 → 右上角扫一扫）"
   → 等待用户完成扫码
   → 验证登录成功（截图确认）

3. 登录态持久化
   → CDP模式会自动保存cookie到独立用户数据目录
   → 下次抓取可直接复用，无需重复登录
```

#### 阶段二：账号数据抓取

```
账号主页抓取清单：

□ 基础信息（截图 + 提取文字）
  - 头像/账号名/抖音号
  - 粉丝数
  - 获赞数
  - 关注数
  
□ 视频列表（滚动抓取）
  - 切换到"作品" tab
  - 滚动加载至少 30 条视频
  - 提取：标题 / 发布时间 / 点赞 / 评论 / 分享
  - 标注播放量>30万的视频
  
□ 合集/TAB分析（若有）
  - 合集列表及视频数
  - 置顶视频分析
  
□ 直播数据（若有）
  - 直播动态
```

#### 阶段三：竞品种草矩阵抓取

```
竞品种草分析步骤：

1. 搜索竞品账号
   → handleNewPage({url: 'https://www.douyin.com/search/[竞品名]?type=user'})
   → 找到竞品官方账号

2. 进入商品tab（若有）
   → handleClick({selector: 'text=商品'})
   → 查看合作带货视频列表

3. 提取达人合作数据
   → 合作视频数
   → 合作达人类型（头部/腰部/KOC）
   → 带货车次（若有）
```

#### 阶段四：评论热词分析

```
评论抓取步骤：

1. 进入播放量最高的前3条视频
2. 点击评论区
3. 滚动加载至少50条评论
4. 提取：
   - 高赞评论（Top 20）
   - 评论关键词词频
   - 用户关注点（口感/包装/价格/功效）
```

### 抖音抓取注意事项

| 风险 | 处理方式 |
|------|---------|
| 抖音反爬（频繁请求） | 每次滚动后等待2-3秒 |
| 视频数量多（100+） | 优先抓取播放量最高的30-50条 |
| 播放量显示模糊（"10w+"） | 截图留存作为引用依据 |
| 部分视频数据隐藏 | 记录"数据受限"，不影响整体分析 |
| 登录态失效 | 重新引导用户扫码 |
